This section is the evidence. It is written for someone checking the claims, and it uses the vocabulary [the glossary](/typescript-as-data/glossary/) defines. Four parts, in reading order. The normative text is the specification itself, generated from `spec/*.md` in the repository at build time. The reference implementation is the evaluator the packages ship, and conformance is what judges it, or yours.
